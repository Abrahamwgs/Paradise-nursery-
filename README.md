# Paradise Nursery

Welcome to Paradise Nursery, your ultimate online destination for high-quality, beautiful houseplants. This project is a React-Redux single-page web application featuring an immersive landing experience, an extensive catalog categorized to suit your home spaces, and a full-featured real-time interactive shopping cart.

## Features
- **Immersive Landing Page**: Beautiful background styling with immediate entrance mechanics.
- **Categorized Plant Catalog**: Includes 3 distinct categories with 6 unique houseplants each, fully equipped with detailed metadata (thumbnails, names, and pricing matrices).
- **Advanced State Management**: Built using Redux Toolkit slices to handle adding, removing, and altering quantities seamlessly.
- **Dynamic Disabled Mechanics**: Intuitively manages "Add to Cart" locks upon action to prevent operational errors.
